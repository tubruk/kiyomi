# Kiyomi Documentation

This directory contains system documentation, architecture designs, developer references, and user guides for the Kiyomi project.

## Directory Structure

- [`backlogs/`](./backlogs/): Features, specifications, or improvements that are planned/proposed but not yet implemented.
- [`design/`](./design/): Core architectural designs, specifications, schemas, protocols, and conceptual specs. Documentation in this folder must remain conceptual and implementation-phase agnostic.
- [`e2e/`](./e2e/): Guides, conventions, and setups for running Playwright-based end-to-end tests.
- [`plugin_developer/`](./plugin_developer/): Guides, quickstarts, and reference manuals for building external provider plugins.
- [`user/`](./user/): Operator guides, user manuals, environment configurations, and setup specs.
