# Backlog: Reader View Options

> **Status**: Proposed / Backlog  
> **Target Components**: `web/src/routes/ReaderPage.tsx`

---

## Overview

Enhance the Web UI reader interface with configurable layout and view controls:
- **Fit Modes**: Fit-to-Width, Fit-to-Height, and Original Size image scaling options.
- **Spread Modes**: Single-Page and Double-Page spread layouts for landscape reading.
- **Reading Direction Toggle**: Quick toolbar toggle between RTL (Right-to-Left), LTR (Left-to-Right), and Vertical (Webtoon) scrolling.
