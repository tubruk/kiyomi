# Backlog: Cache Management UI

> **Status**: Proposed / Backlog  
> **Target Components**: `web/src`, `internal/api`

---

## Overview

Add a settings section in the Web UI for inspecting and managing local server cache:
- **Disk Usage Metrics**: Display current disk space consumed by cached images and temporary files.
- **Clear Cache Actions**: One-click actions to purge image cache or reset cached provider metadata.
- **TTL & Limit Controls**: Basic options to configure maximum cache size and retention periods.
