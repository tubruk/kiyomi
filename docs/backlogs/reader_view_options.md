## Overview

Implement Double-Page spread layouts for landscape reading in the Web UI reader interface.

Other reader view options (Fit Modes and Reading Direction Toggle) have already been implemented, but **Spread Modes** was skipped and remains in the backlog:
- **Spread Modes**: Add support for Single-Page and Double-Page spread layouts for landscape reading.
- **Page Reconciliation**: Ensure page indices and progress tracking are properly handled when displaying two pages side-by-side.
